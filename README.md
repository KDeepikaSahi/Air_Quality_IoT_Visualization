🌍 Air Quality Monitoring and Visualization (IoT Project)
📌 Project Overview

This project implements an IoT-based Air Quality Monitoring System that collects, processes, stores, and visualizes environmental data for five German cities:

Berlin
Munich
Dresden
Essen
Zwickau

The system uses:

Node-RED → Data collection & processing
InfluxDB → Time-series data storage
Grafana → Data visualization dashboard

The goal is to provide clear, real-time insights into air quality for better environmental understanding and decision-making.

Covers topics such as:
- IoT architecture and protocols
- Sensor data processing
- Visualization and analytics

This is a working repository of academic progress and project artifacts.
